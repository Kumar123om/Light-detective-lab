# 🔦 Light Detective Lab - Class 6 Science

An interactive, gamified, and visual web application designed for Class 6 Science students to explore **Light, Shadows, and Materials (Transparent, Translucent, and Opaque)**.

## 🌟 Key Features
- 🔬 **Virtual Flashlight & Shadow Tester**: Test 9 everyday objects (Glass, Water, Butter Paper, Wood, Metal, etc.) to see light ray transmission and real-time shadow formation.
- 📏 **Shadow Distance Slider**: Change the object's distance from the torch to observe how shadow size scales.
- 🎯 **Material Sorting Challenge**: Drag-and-drop or tap-to-select game to categorize objects into Transparent, Translucent, and Opaque bins.
- 💡 **Visual Concept Explorer**: Ray diagrams explaining *why* light behaves this way.
- 🧠 **Science Detective Quiz**: 5 interactive questions with instant feedback and canvas confetti rewards.
- 🔊 **Synthesized Web Audio**: Built-in sound effects (pops, chimes, fanfares, mute toggle).
